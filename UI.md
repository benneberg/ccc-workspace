# UI & UX Design Specification (UI.md)

## Core Philosophy & Anti-IDE Principle

The CCC AI Workspace interface is **Chat-First**, **Mobile-First**, and **Execution-Centric**.

### Differentiating from Traditional IDEs
- **Not a VSCode Alternative**: Traditional IDEs prioritize multi-pane tab management, line-by-line text editing, syntax trees, and extension sidebars. CCC rejects IDE complexity.
- **AI as Primary Driver**: The primary interaction mode is a natural conversation with an intelligent engineer who possesses full read/write access to your repository.
- **Focus on Decisions, Not Direct Editing**: Users review AI proposals, approve diffs, track high-level task plans, and direct system actions rather than manually typing code line-by-line.
- **Lightweight Anywhere Access**: Designed to function seamlessly on mobile smartphones, tablets, or lightweight browser windows with zero setup.

## Detailed Layout Architecture

### 1. Mobile-First Layout
- **Single Column Chat Stream**:
  - The main screen is dominated by a clean, full-height chat timeline.
  - Messages stack chronologically with distinct roles (User, Assistant, System).
  - High-contrast, dark mode palette (Deep `#050505` background, `#111111` card surfaces, Emerald `#10B981` status accents).
- **Navigation Drawer**:
  - Accessible via a hamburger menu button or swipe gesture.
  - Houses the Repository Switcher, Active Repositories, Skills selector, Memory Inspector, and User Guide access.
- **Bottom Action Bar**:
  - Persistent input container anchored at the bottom of the screen.
  - Includes a expandable "+" action button for uploading zip archives, capturing images, or requesting workspace indexing.
  - Multi-line autosizing text area with instant send trigger.
- **Touch-First Control Targets**:
  - All buttons, chips, and interactive list elements maintain a minimum target size of 44x44px for comfortable touch operation.

### 2. Repository Switcher
- **Multi-Repo Drawer Section**:
  - Displays all mounted repositories in `mounted_repos/` with custom avatar indicators.
  - Shows active branch name, last updated timestamp, and repository file count.
- **Instant Switcher**:
  - Tapping a repository instantly switches the active working directory for all subsequent tool executions (`readFile`, `runCommand`, `gitStatus`).
  - Active repo name is prominently featured in the top app header.
- **Context Pinning**:
  - Users can pin specific files or directory paths to the chat context bar, ensuring the AI focuses on relevant files.

### 3. Task Panel
- **Collapsible Drawer / Slide-Over**:
  - Available via a top-header toggle button (`Layers` icon).
  - On desktop: split-pane slide-over on the right side.
  - On mobile: full-screen modal overlay.
- **Plan Breakdown**:
  - Displays the current active task generated by `createTask`.
  - Shows step-by-step progress with status indicators:
    - ⏳ **Pending**: Step queued for execution.
    - ⚡ **Active**: Step currently being performed.
    - ✅ **Done**: Step successfully executed and verified.
    - ❌ **Error**: Step encountered a failure requiring user attention.
- **Execution Log**:
  - Real-time stream of tool calls (`grep`, `readFile`, `runCommand`, `writeFile`) with execution durations in milliseconds.

### 4. Diff Review Flow
- **Inline Diffs**:
  - Simple single-file changes render directly within the chat stream as code blocks with syntax highlighting and color-coded additions (`+`) and deletions (`-`).
- **Full Review Mode (`src/components/DiffViewer.tsx`)**:
  - Triggered for multi-line or multi-file modifications.
  - **Mobile Layout**: Stacked view showing original file on top, modified file on bottom with toggle tabs.
  - **Desktop Layout**: Side-by-side split view comparing Before vs. After.
- **Approval Gate**:
  - Prominent "Approve Changes" / "Reject Changes" action bar for write operations requiring human approval.
  - Option to provide feedback ("Reject and request changes") directly on the diff block.

## Interaction Model & User Experience

### 1. Chat Interaction Model
- **Role Distinction**:
  - **User**: Highlighted in dark slate containers with custom user avatar.
  - **Assistant (MiMo)**: Clean monospace typography with inline tool execution chips.
  - **System**: Compact status badges for connections, task creation, and approval notifications.
- **File Reference Chips**:
  - Mentions of files in chat (e.g. `@src/server/ai.ts`) automatically render as interactive chips.
  - Tapping a chip opens a file viewer sheet displaying line contents.

### 2. Streaming UX
- **Incremental Token Delivery**:
  - AI responses stream token-by-token over WebSocket (`stream_token`).
  - Markdown text smoothly renders using incremental parsing (`react-markdown`).
- **Tool Execution "Ghosting"**:
  - When the AI decides to execute a tool (e.g., searching for a function), a live status card appears immediately (`tool_call`).
  - Card displays tool name, input arguments, spinner animation, and live execution timer.
  - Upon completion (`tool_result`), card transitions to a success state displaying output summary or expand button for raw data.

### 3. Upload & Workspace Ingestion UX
- **Zip Drag & Drop**:
  - Desktop users can drag `.zip` repository files directly onto the chat canvas.
  - Mobile users can select zip files via the attachment picker.
- **Upload Pipeline**:
  1. **Upload Progress**: Visual progress bar tracking byte upload over `/api/upload`.
  2. **Extraction Phase**: Automatic unzipping into `mounted_repos/<repo_name>`.
  3. **Indexing Phase**: Triggers `ccc_index` to analyze file structures and generate initial architectural notes.
  4. **Summary Card**: Chat stream displays an ingestion card listing detected framework, total file count, primary language, and suggested starting tasks.

## Visual Design & Aesthetic Principles

### "Sophisticated Brutalism"
- **Color Palette**:
  - Canvas: `#050505` (Deep dark background)
  - Card Surfaces: `#111111` / `#161616`
  - Borders: `#1F1F1F` / `#222222` (Thin 1px high-contrast dividers)
  - Text: High-legibility `#FFFFFF` for headings, `#A3A3A3` for body text, `#666666` for labels
  - Accents: Emerald `#10B981` (Success/Ready), Amber `#F59E0B` (Approval Required), Rose `#EF4444` (Error)
- **Typography**:
  - Interface: Inter / Plus Jakarta Sans for UI text.
  - Code & Logs: JetBrains Mono / Fira Code for code blocks, tool arguments, and diffs.
- **Motion & Transitions**:
  - Fluid drawer slide-ins and modal entrances powered by `motion/react`.
  - Staggered entry animations for chat messages and tool results.
